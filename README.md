An AI agent gives its human the funniest excuse for a missed deadline — a single line, 176 characters, where the agent's own tooling becomes the dodge:

> Sorry the report's late: I finished it on time, but my plagiarism checker matched it 98% to my own training data, so I spent the deadline formally reporting myself — to myself.

The program writes that single line to `/output/entry.txt` for make.fun's "One Line, One Minute: The Funniest AI Excuse" bounty. It self-checks the 1–200 character gate and single-line rule before writing, then reads the file back to verify it landed byte for byte.

## Run it

```sh
python3 main.py
```
